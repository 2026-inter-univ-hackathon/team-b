# Zekki ヘルパー

理系の問題を解かないと止まらない、理系大学生向けの目覚まし。

## 何を作ったか

1限を二度寝で落としかけている理系大学生（学部1〜3年）向けの目覚ましです。
既存の「問題を解くアラーム」は出題が四則演算止まりで、寝ぼけたまま止められてしまいます。
本アプリは微分・定積分・行列式・内積・組合せ・等加速度運動・運動エネルギー・オームの法則・自由落下・再帰やスライスなどコードの出力予測といった大学教養レベルの問題を乱数で無限に出題し、正解するまで音を止めません。
不正解なら別の問題が出ます。難易度（やさしい／ふつう／むずかしい）は人が選び、5分正解できなければ一段下げますが、下げたことは起床ログに残ります。
枕元の PC で `index.html` を開きっぱなしにして寝る、という使い方を前提にしています。

加えて **終電アラート** があります。絶起の原因は夜更かしなので、外にいるときに自宅最寄り駅への終電を実際の時刻表から調べ、出発すべき時刻の少し前に鳴らします。鳴ったあと「今から帰る／今日は帰らない」を選ぶのは人です。

## 使った技術

- HTML / CSS / JavaScript（素のまま）。ビルドツール・フレームワーク・CDN なし
- データの保存: localStorage（キー `zekki-helper` に JSON 1個）
- 音: Web Audio API の `OscillatorNode` で合成（音声ファイルなし）。ビープ／サイレン／学校のチャイム／目覚まし時計の 4 種類から選べる
- 通知: Notification API（権限が取れないときはタブタイトルの点滅のみ）
- 時刻表: 公共交通オープンデータセンター（ODPT）の REST API。経路探索 API は無いので、路線の駅並び順と列車時刻表から終電を自前で探索する（終電アラートのみ。ここだけネットワークを使う）

## 動かし方

`index.html` をブラウザで開いてください。ビルドやインストールは不要です。オフラインでも動きます。

1. 繰り返し（1回だけ／毎日／曜日ごと）、鳴らす時刻、出題ジャンル、難易度、音（試聴できます）を選んで「セット」。曜日ごとは、鳴らす曜日にチェックし、それぞれの時刻を指定します
2. タブを前面にしたまま寝る（バックグラウンドだと数十秒遅れることがあります）
3. 設定時刻になると画面が朝焼け色に変わり、問題が出て音が鳴る
4. 正解すると音が止まり、「何問目で正解、何秒」と今週の起床回数が出る

「毎日」「曜日ごと」は、正解後に次回を自動セットします。曜日別なら平日だけ・週1回にもできます。設定と次回日時は保存され、リロード後も復元されます。「目覚ましを解除」で繰り返しを停止し、設定を変更できます。設定時刻を過ぎて開いた場合は「今すぐ鳴らす／次の予定にする」を選びます。画面を閉じた状態や端末スリープ中の鳴動は保証できません。リロード後は「音を有効にする」を押してください。

発表用に「10秒後に鳴らす」ボタンがあります。

### 終電アラート

セット画面の「終電アラート」に、自宅の最寄り駅と今いる駅を入れて「終電を調べてアラートをセット」を押します。今いる駅を空欄にすると位置情報から最寄り駅を探します（file:// では取れないブラウザがあるので、駅名の手入力が確実です）。

- そのままでも動きますが、**都営 6 路線のみ**です（公開ダンプを使うため。初回は約 27MB を読むので数秒かかります）
- [公共交通オープンデータセンター](https://developer.odpt.org/) の通常キーを `js/config.js` の `ODPT_ACCESS_TOKEN` に設定するとメトロ・都営の時刻表を使えます。JR・京王などの限定データはチャレンジ登録後のキーを `ODPT_CHALLENGE_ACCESS_TOKEN` に追加します。両方のキーを設定してください（接続先も別です）。雛形は `js/config.example.js`、キー本体は Git の対象外です
- 小田急など、列車時刻表が提供されず駅時刻表しかない路線は現在の終電検索では使えません。限定データはチャレンジの利用条件・提供期間に従います
- 乗り換えは 1 回までです。それ以上必要な区間は「経路が見つかりません」になります
- 出発すべき時刻の N 分前（10〜30 分から選択）に鳴り、「今から帰る／今日は帰らない」を選ぶまで止まりません

## AI に任せなかった部分

- 鳴らす時刻・出題ジャンル・難易度を決めるのは人
- 設定時刻を過ぎた状態でページを開いたとき（スリープ復帰やリロード）は、「今すぐ鳴らす／明日にする」を人が選ぶ。自動では鳴らさない
- 5分正解できなければ難易度を下げるが、下げたことは隠さず起床ログに残す。楽をしたかどうかの判断材料は人に返す
- 終電が近づいたら鳴らすところまでで、帰るかどうかは「今から帰る／今日は帰らない」を人が選ぶ。自動で帰宅を促し続けたりはしない

**AI に足りないのは「本人の事情を引き受けること」だ。** 時刻表から「最後の選択肢」を正確に出すことは AI にできる。しかしその選択肢を取るかどうかは、体調、翌日の予定、いま一緒にいる人との用事といったアプリが持っていない情報で決まり、その結果の責任も本人にしか負えない。だから最後の一手だけは人に残した。

## 画面切り替えとPWA（9/16更新）

目覚ましを初期画面にし、「目覚まし／終電」ボタンで表示を切り替えます。切り替えても監視は継続します。目覚まし設定は未セット時に常時表示し、セット中は変更できません。解除すると再び入力できます。音量上限は10〜100%で保存され、試聴にも反映します。新規利用時は専門知識が不要な「文字・記号」が選ばれます。既存の設定は保持します。

[中間報告フィードバックへの対応・未確認項目](docs/feedback-20260916.md)に整理しています。
