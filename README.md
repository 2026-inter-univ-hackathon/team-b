# 積分アラーム

アラームを止めても二度寝してしまう理系大学生向けに、積分の計算問題を解かないと止められない目覚ましアプリ

## 何を作ったか

理系大学生は、アラームを止めた瞬間に意識が落ちて二度寝してしまいがち。
このアプリは、セットした時刻になるとアラームが鳴り、難易度違いの積分の定積分問題が3つ候補で出る。
その中から1つを選んで実際に計算し、答えが合っていないとアラームが止まらない。
「頭を使わないと止まらない」ことで、二度寝への逆戻りを防ぐ。

`index.html` をブラウザで開いてください。ビルドやインストールは不要です。

## AI に任せなかった部分

アラームが鳴ったとき、どの難易度の問題を解くかは必ず人が選ぶ（アプリは3つ候補を出すだけ）。
答えが合っているかを最終的に確かめて「起きる」に進むのも人。
難易度選択や正解判定まで全自動にすると、眠くて簡単な問題ばかり選んでしまい、
本当に起きたかどうかを確認できなくなるため。
