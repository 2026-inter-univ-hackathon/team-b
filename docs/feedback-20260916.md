# 中間報告フィードバックへの対応（2026-09-16）

主役は「問題を解いて二度寝を防ぐ目覚まし」。終電は帰宅を助ける補助機能として残し、画面内の切り替えで分離する。機能の削除や設定専用ページは導入しない。

| 指摘 | 対応 |
| --- | --- |
| コアが伝わりにくい | 初期表示を目覚ましに限定し、冒頭で価値を説明 |
| 同時表示で縦に長い | 目覚まし／終電を切り替え。一方を隠しても監視は継続 |
| 設定を開くボタンとセットが近い | 設定開閉を廃止。未セット時は直接入力、セット操作は区切り線の下 |
| 解除後に入力しにくい | 設定欄は解除時に再表示・有効化し、時刻にフォーカス。前回の折りたたみ方式を撤去 |
| 時刻欄のはみ出し | 入力とfieldsetの最小幅を解除し、スマホの文字・余白を調整 |
| 月が霞む | カードの裏ではなく、見出し横に独立した月を配置 |
| 音量を調整したい | 10〜100%の上限を保存。段階的増音はその上限まで、試聴は上限音量。端末音量との組み合わせ |
| 難易度差が小さい | やさしい数学は一段の計算／一次方程式に限定。ふつう・むずかしいでは項・手順・行列サイズを増加 |
| 数学への拒否感／種類不足 | 毎回生成する記号カウントと数字の位置問題を追加。文字列長・紛らわしさを難易度別に変更。連続で同じ問題型を出さない |
| 終電入力が下から上 | 出発→下矢印→到着の順に統一 |

漢字の固定問題集は追加していない。「問題文と答えの固定リストを持たない」という既存方針に沿って、知識不要の文字・記号問題で選択肢を増やした。難易度の体感が妥当かは、人による試用が必要。

## 確認したこと

- Nodeでセット→解除→編集→再セットと、機能切り替え中の監視継続を確認。
- 4ジャンル×3難易度×150問（1800問）を生成し、整数解・ジャンル・問題型の連続回避を検証。文字・記号の答えは問題文から独立に計算して照合。
- 音量10/50/100%の開始音量・増音上限・試聴・停止を音声APIのモックで検証。
- 既存のODPTとPWAテスト、構文チェック、差分チェック。

## 未確認・チームで決めること

- ブラウザのローカルファイル表示が自動承認レビューで拒否されたため、実画面での操作・幅320/375/390pxの表示とSafari/Chrome差は未確認。CSSとDOMを模したテストは実画面の保証ではない。
- iPhone/Android実機で時刻変更、解除後の再入力、タブ切り替え中の鳴動、文字列の読みやすさ、端末音量との関係を確認する。
- Android向けの当面の実装対象は共通Web/PWA版。Androidネイティブ版は今回追加していない。iOSネイティブ版は別実装のまま。
- Web版では画面を開いた状態で使う前提を維持。画面ロック・バックグラウンド・終了後のアラームを保証するものではない。
- MTGの時刻や最終コンセプトの合意はチームで決める。今回、予定登録やチームへの送信は行っていない。

## 参考画像に合わせた調整（9/17）

提供された5枚を参考に、濃紺・方眼背景・オレンジの操作ボタン・見出し下の機能切り替えに統一。科目と難易度の選択状態を枠と背景でも表現する。解除後に直接編集できる構成は維持する。

終電は検索結果から残り時間と縦の経路表示を生成し、発着時刻・乗り換えに使える時間・乗車時間を表示する。参考画像の番線や固定の残り時間は転記しない。鳴動中は濃紺の問題画面にまとめる。

複数アラームの追加・編集・削除やラベル機能は今回追加していない。既存の単一アラームに合わせた視覚面の反映。経路表示の自動テストは通過、スマホ実画面の見た目は未確認。
